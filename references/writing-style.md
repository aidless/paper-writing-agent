# 学术写作规范（浓缩版）

## IMRaD 结构与时态

- Introduction：漏斗式——背景与重要性（已知，现在时）→ 文献缺口（未知）→ 本研究补什么（现在时）。
- Methods：过去时；Participants → Materials → Procedure → Data Analysis；细节到可完全复现。
- Results：过去时；先描述性统计再推断统计；每段聚焦一个分析；趋势和模式进图表，数据与 p 值进文字。
- Discussion：倒漏斗——重述主要发现（过去时）→ 解释（现在时）→ 与文献比较 → 局限与未来 → 结论。
- Abstract 最后写，数字必须与 Results 完全一致。

## Hedging（软化断言）

写作不是"我证明了 X"，而是"证据支持 X"。

| 太强 | 更好 |
|---|---|
| This proves that... | This provides evidence for... |
| X causes Y. | These results are consistent with X influencing Y. |
| This is the first study. | To our knowledge, this is the first study. |
| The data show... | The data suggest... |
| It is clear that... | It appears that... |

常用词：may, might, could, appear, seem, suggest, indicate, tend to, likely, potentially, to some extent。

## 主动 vs 被动

- 描述自己做了什么：主动（We did X）。
- 报告已知事实：主动或被动皆可。
- 执行者不重要：被动（Participants were recruited...）。
- 避免无主句：It was then analyzed. ❌

## 数字与统计报告

- 每个统计量注明检验、自由度、效应量与置信区间：`t(df) = val, p = val, d = val, 95% CI [lo, hi]`。
- CI 必须 lo <= hi；效应量与 CI 符号一致；百分比不得自相矛盾。
- 种子数/样本量全文一致：摘要、正文、表格、caption 必须同一口径。
- 校正后的 p 值要标注校正方法（Bonferroni/Holm/FDR）；报校正后值与原始值并存时标明。

## 常见中式英语错误

1. 冠词系统：a/an/the 缺失或误用。
2. according to 只用于引用他人说法，不用于"根据数据"。
3. 长名词短语作主语：The fact that... → That...。
4. 冗余副词：very important → critical/essential；totally different → different。
5. 过度使用 can：the results can show that... → the results suggest that...。
6. on the one hand... on the other hand 只用于对比冲突观点，不用于列举两点。
7. 平行结构：for collecting, analyzing, and to interpret → ...and interpreting。
8. research 不可数，无 researches。

## 回复审稿人（Rebuttal）结构

礼貌开头（感谢每条意见）→ 逐条回应（引用或转述意见 → 做了什么修改/为何不改 → 附修改后原文）→ 结尾致谢。

- 感谢每条意见，即使不同意：We appreciate this observation.
- 具体说明改了什么、怎么改的；列出修改后文本或行号。
- 逐条回应，不跳过任何评论。
- 不同意时给出证据：We respectfully disagree because... with supporting evidence.
