# Academic Writing Conventions (condensed)

## IMRaD structure and tense

- Introduction: funnel-style — background and importance (known, present tense) → literature gap (unknown) → what this study contributes (present tense).
- Methods: past tense; Participants → Materials → Procedure → Data Analysis; detailed enough to be fully reproducible.
- Results: past tense; descriptive statistics before inferential statistics; one analysis per paragraph; trends and patterns go into figures/tables, data and p-values go into prose.
- Discussion: inverted funnel — restate the main findings (past tense) → interpret (present tense) → compare with the literature → limitations and future work → conclusion.
- Abstract is written last; its numbers must exactly match the Results.

## Hedging (softening claims)

Writing is not "I proved X" but "the evidence supports X."

| Too strong | Better |
|---|---|
| This proves that... | This provides evidence for... |
| X causes Y. | These results are consistent with X influencing Y. |
| This is the first study. | To our knowledge, this is the first study. |
| The data show... | The data suggest... |
| It is clear that... | It appears that... |

Common hedges: may, might, could, appear, seem, suggest, indicate, tend to, likely, potentially, to some extent.

## Active vs. passive voice

- Describing what you did: active (We did X).
- Reporting known facts: active or passive, either is fine.
- When the agent is unimportant: passive (Participants were recruited...).
- Avoid agentless sentences: It was then analyzed. ❌

## Numbers and statistics reporting

- For each statistic, state the test, degrees of freedom, effect size, and confidence interval: `t(df) = val, p = val, d = val, 95% CI [lo, hi]`.
- The CI must satisfy lo <= hi; the effect size and CI must have consistent signs; percentages must not be self-contradictory.
- Seed count/sample size must be consistent throughout: Abstract, body, tables, and captions must all share the same figures.
- Corrected p-values must specify the correction method (Bonferroni/Holm/FDR); when reporting both corrected and raw values, say so.

## Common Chinglish errors

1. Article system: missing or misused a/an/the.
2. "according to" is used only for quoting others' claims, not for "based on the data."
3. Long noun phrases as subjects: The fact that... → That....
4. Redundant adverbs: very important → critical/essential; totally different → different.
5. Overusing can: the results can show that... → the results suggest that....
6. "on the one hand... on the other hand" is only for contrasting opposing views, not for listing two points.
7. Parallel structure: for collecting, analyzing, and to interpret → ...and interpreting.
8. Research is uncountable; there is no "researches."

## Rebuttal structure

Politely thank each comment → respond point by point (quote or paraphrase the comment → state what was changed / why it was not → attach the revised text as-is) → close with thanks.

- Thank each comment, even when you disagree: We appreciate this observation.
- Say specifically what was changed and how; list the revised text or line numbers.
- Respond to every comment in order; skip none.
- When you disagree, give evidence: We respectfully disagree because... with supporting evidence.
